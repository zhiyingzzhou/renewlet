# Renewlet v0.3.35

Renewlet v0.3.35 新增账户余额记录，调整了手动续订，并改进了 AI 识别。感谢 [@rysyd](https://github.com/rysyd) 提出的余额需求（[#101](https://github.com/zhiyingzzhou/renewlet/issues/101)），以及 [@Flying-Ace](https://github.com/Flying-Ace) 对手动续订的反馈（[#102](https://github.com/zhiyingzzhou/renewlet/issues/102)）。

## 账户余额

- 新增或编辑订阅时，开启“记录账户余额”，即可填写余额和币种，在订阅卡片和详情中查看。每个订阅单独记录，余额币种可以与订阅价格币种不同。
- 余额需要手动更新，不会自动扣减或计入支出。导入、导出和备份会一并保留余额。

## 手动续订

- 在订阅的“···”菜单中选择“续订”，可以提前续订，过期后也能直接续订，无需先恢复状态。
- 续订默认“延续原周期”，已过期的订阅也一样。提前续订从原到期日往后延；已过期则按原周期推进到今天之后最近的一期。需要换个开始日期时，再选“重新开始订阅”。
- 防止重复点击导致多续一期；遇到网络异常、无法确认保存结果时，会提示先刷新核对。

## 其他调整

- AI 识别可以同时提交文字和截图，不再需要切换输入方式。
- 识别固定期限服务时，购买日期和期限明确的，可以补全到期日，并判断是否已过期。
- 新增、编辑和续订保存失败时保留输入，后台刷新也不会覆盖正在填写的内容。
- 修复手机续订弹窗中日期控件遮挡底部按钮的问题。

## 升级提示

- 升级后请刷新已打开的页面。
- AI 设置中的“OpenAI”改用 Responses 接口。使用仅支持 Chat Completions 的第三方服务时，请选择“OpenAI Compatible”。
