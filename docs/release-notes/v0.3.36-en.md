# Renewlet v0.3.36

Renewlet v0.3.36 fixes an issue that prevented subscriptions with cost sharing from being restarted.

[中文 ->](./v0.3.36-zh.md)

---

## Fixes

- Fixed an issue where choosing **Restart subscription** would fail if a member's join date fell outside the new subscription period.
- Fixed member join date validation showing raw error codes. It now explains which dates need changing and the allowed range.

## Improvements

- When restarting a subscription, members whose join dates need adjusting are listed with their original dates. The new start date is filled in as a suggestion and can be changed for each member. Changes are saved when you confirm the renewal; other members' dates stay unchanged.
- Collection reminders follow the adjusted dates. Members' contribution amounts, notes, and the account balance are preserved.
