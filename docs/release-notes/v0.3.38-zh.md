## 暂停和恢复订阅

- 暂停后，这项订阅的续费和到期提醒就停了。账单日期、余额和家庭分摊记录都会保留，家庭收款提醒照常发送。
- 恢复时可以选“活跃”或“试用”。原来的账单日或试用结束日如果已经过了，改好日期再保存。

## 其他调整

- 用手机看首页和公开状态页时，统计卡里的金额、币种和说明文字现在能换行显示。
- 首页“月均支出”用的是当月锁定汇率或内置参考汇率时，金额下方会注明。
- 浅色和深色模式下，已过期、已暂停和已取消的订阅卡片与其他卡片使用相同的底色和边框。日期、状态标签、键盘焦点和批量选中标记更容易辨认。
