## Before You Upgrade

One-click deploy users should run `Sync Renewlet Upstream` in the existing generated repository instead of starting a new one-click deployment.

Back up your data before upgrading. To return to v0.3.27 or earlier, you must restore the pre-upgrade data along with the previous Docker image or Worker. Restoring the backup discards any data added or changed after it was taken.

## New Features

- Added “Русский” to the language settings. “Follow system” now recognizes Russian as well.
