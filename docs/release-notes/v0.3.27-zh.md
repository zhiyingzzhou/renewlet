# Renewlet v0.3.27

Renewlet v0.3.27 把公开状态页的可见性管理做得更完整，也加入了中国农历日期显示。

[English ->](./v0.3.27-en.md)

---

## 升级前请先读

Cloudflare 用户按原来的升级流程更新即可。新增的公开状态页字段会由部署流程自动迁移；一键部署用户请在原来的生成仓库运行 `Sync Renewlet Upstream`，不要重新点击一键部署。

## 改进

- 公开状态页可以分别隐藏已过期订阅和长期买断订阅，设置页会显示对应数量，并提供预览后批量隐藏或恢复的快捷操作。
- 订阅列表新增公开可见性管理。可以选择单条、当前页或所有匹配结果，批量隐藏或恢复订阅在公开状态页上的展示。
- 设置中新增“中国农历日期”开关。打开后，日期选择器会同时显示公历和农历；账单、提醒和日历使用的日期不会改变。

## 修复

- 修复历史一次性订阅的服务期为空时，筛选、公开状态页计数和公开可见性批量处理判断不一致的问题。
- 修复公开状态页关闭后，订阅列表仍显示公开可见性管理入口的问题。
