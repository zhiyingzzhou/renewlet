# Renewlet v0.3.39

This release adds category grouping for subscriptions and single sign-on. Thanks to [@ZvonimirSun](https://github.com/ZvonimirSun) for both suggestions ([#111](https://github.com/zhiyingzzhou/renewlet/issues/111), [#112](https://github.com/zhiyingzzhou/renewlet/issues/112)).

## Subscription list

- **Group by category** is off by default. Turn it on in grid or list view to see categories in the order you set in Settings, with pinned subscriptions first in each group.
- The category filter shows how many subscriptions each category has. Select several to see matches from all of them. You can still select a category that only older subscriptions use.

## Single sign-on

- Admins can connect an OIDC provider such as authentik or Auth0 under **Settings → Access security**.
- Sign in to your existing Renewlet account and link it under **Settings → Account**. Next time, choose **Use single sign-on** on the sign-in page.
