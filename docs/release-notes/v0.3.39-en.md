# Renewlet v0.3.39

You can now group your subscriptions by category. Thanks to [@ZvonimirSun](https://github.com/ZvonimirSun) for suggesting this in [#111](https://github.com/zhiyingzzhou/renewlet/issues/111).

## Subscription list

- **Group by category** is off by default. Turn it on in grid or list view to see categories in the order you set in Settings, with pinned subscriptions first in each group.
- The category filter shows how many subscriptions each category has. Select several to see matches from all of them. You can still select a category that only older subscriptions use.
