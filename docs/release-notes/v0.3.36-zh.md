# Renewlet v0.3.36

Renewlet v0.3.36 主要修复家庭共享订阅重新开始时报错的问题。

[English ->](./v0.3.36-en.md)

---

## 修复

- 修复家庭共享订阅选择“重新开始订阅”时，因成员上车日期超出新订阅范围而无法保存的问题。
- 修复成员上车日期校验失败时直接显示错误代码的问题，现在会提示需要修改的日期及可选范围。

## 改进

- 重新开始订阅时，会列出需要调整上车日期的成员，显示原日期并预填新的开始日期，也可以逐个修改。确认续订后一起保存，其他成员的日期保持不变。
- 收款提醒会按调整后的日期计算，成员分摊金额、备注和账户余额保留。
