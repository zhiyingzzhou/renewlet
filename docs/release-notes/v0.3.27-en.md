# Renewlet v0.3.27

Renewlet v0.3.27 makes public status visibility easier to manage and adds optional Chinese lunar dates.

[中文 ->](./v0.3.27-zh.md)

---

## Before You Upgrade

Cloudflare users can upgrade through the existing deployment flow. The new public status fields are migrated automatically; one-click deploy users should run `Sync Renewlet Upstream` in the existing generated repository instead of starting a new one-click deployment.

## Improvements

- Public status pages can now hide expired and lifetime subscriptions separately. Settings shows the matching counts and provides a preview before hiding or restoring them in bulk.
- Subscription management now includes public visibility management. Select individual subscriptions, the current page, or all matching results to hide or restore them on the public status page.
- A new “Chinese lunar dates” setting shows Gregorian and lunar dates together in date pickers. Billing, reminders, and calendar calculations continue to use the same dates.

## Fixes

- Fixed inconsistent filtering, public status counts, and bulk visibility handling for older one-time subscriptions with an empty term count.
- Fixed the public visibility management entry remaining available after the public status page was disabled.
