# Renewlet v0.3.38

Added the option to pause and resume subscriptions. Thanks to [@betteryjs](https://github.com/betteryjs) ([#110](https://github.com/zhiyingzzhou/renewlet/issues/110)).

[中文 ->](./v0.3.38-zh.md)

## Pausing and resuming subscriptions

- Pausing stops renewal and expiry reminders for that subscription. Your billing dates, balance and family cost-sharing records are kept, and any scheduled family collection reminders still go out.
- Choose **Active** or **Trial** when you resume. If the billing date or trial end date has already passed, update it before saving.

## Other changes

- On mobile, amounts, currency codes and captions now wrap on the dashboard and public status page.
- **Monthly spend** on the dashboard now shows when the amount uses the month’s locked exchange rates or the built-in reference rates.
- Expired, paused and cancelled subscriptions now use the same card surface as other subscriptions in light and dark mode. Dates, status labels, keyboard focus and bulk selections are easier to see.
