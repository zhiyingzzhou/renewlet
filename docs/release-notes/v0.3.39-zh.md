## 订阅列表

- “按分类分组”默认关闭，网格和列表都能开启。分组后，分类按设置里的顺序排列，置顶订阅排在各自分类的最前面。
- 筛选分类时能看到每个分类有多少订阅。勾选多个分类，会一起显示这些分类里符合条件的订阅。旧订阅还在用的分类也能选。

## 单点登录

- 管理员可以在“设置 → 访问安全”接入 authentik、Auth0 等 OIDC 服务。
- 先用原来的 Renewlet 账号登录，在“设置 → 账号”里完成绑定，以后就能在登录页选“使用单点登录”了。
