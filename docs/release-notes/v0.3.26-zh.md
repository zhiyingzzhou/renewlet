# Renewlet v0.3.26

Renewlet v0.3.26 让页面切换更有反馈，也提升了订阅列表和通知历史在数据量较大时的稳定性。

[English ->](./v0.3.26-en.md)

---

## 改进

- 页面切换时显示顶部进度条，加载较慢时也能看到当前状态。
- 订阅列表的筛选和排序改为按完整结果处理，分页和后台刷新时更准确、更顺畅。
- 通知历史的长消息改为单独保存，发送详情不会因为内容过长而丢失。

## 修复

- 修复在 Logo/Icon 搜索面板点击搜索后面板误关闭，以及搜索结果返回后面板状态丢失的问题。
- 修复 Cloudflare 本地启动时没有订阅的用户被错误判定为调度状态异常的问题。
