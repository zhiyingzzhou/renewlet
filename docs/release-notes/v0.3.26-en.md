# Renewlet v0.3.26

Renewlet v0.3.26 adds clearer feedback during navigation and improves subscription lists and notification history as your data grows.

[中文 ->](./v0.3.26-zh.md)

---

## Improvements

- A progress bar now appears at the top during page navigation, so slow loads provide visible feedback.
- Subscription list filtering and sorting now use the complete result set, making paginated views and background refreshes more accurate and responsive.
- Long notification messages are stored separately, so notification details are not lost when the content is large.

## Fixes

- Fixed an issue where clicking Search in the logo or icon picker could close the panel or lose its state when results returned.
- Fixed a Cloudflare local startup error for users without subscriptions.
