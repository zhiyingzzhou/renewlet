# Renewlet v0.3.37

周付订阅不用等本周续费，日历里就能看到下周和再下一周的扣费日期了。感谢 [@Flying-Ace](https://github.com/Flying-Ace) 在 [#108](https://github.com/zhiyingzzhou/renewlet/issues/108) 里指出这个问题。

---

## 续费日历和首页

- 日历按订阅周期列出所选月份的每次续费，推算出的日期标为“预计”。查看这些日期不会产生付款记录，也不会改变订阅里保存的下次扣费日期。
- 首页“即将续费/到期”按日期列出最近 5 次续费或到期事件。想看更远的日期，可以直接点“查看日历”。

## 其他调整

- 统计页的“本月预计扣费”会算上从今天到月底的每一期，周付订阅不再只算一次。每月 31 日续费的订阅，经过二月后，三月仍按 31 日预计扣费。
- 手机上，订阅卡片的开始日期和到期日期会在空间足够时保持同一行。
